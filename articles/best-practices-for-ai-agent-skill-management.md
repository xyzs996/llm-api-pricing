## Novice Pitfalls: Avoiding Common Mistakes

90% of beginners fixate on tools (e.g., Pi's 4 default tools: read/write/edit/bash) instead of defining clear task boundaries. Example: A security team's bug bounty process improved 3x by adding context to Skill **package**, not just using new tools. Use the "Agent Skill Checklist": Define task → add context → set permissions → test → iterate. Start with low-risk tasks (e.g., report generation) before scaling to high-stakes work (e.g., financial analysis).
